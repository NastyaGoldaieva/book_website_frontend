# book_website_frontend

Prerequisites
- Node.js 16+
- npm або yarn

Кроки для запуску
1. Перейти у папку фронтенду:
```bash
cd frontend
```
2. Встановити залежності:
```bash
npm install
```
3. Створити `.env`:
```
REACT_APP_API_URL=http://localhost:8000/api
```
4. Запустити dev-сервер:
```bash
npm start
```
